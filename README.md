# UpdownStock

축제 부스용 주식 일봉 차트 예측 게임입니다.

참가자는 실제 일봉 차트를 보고 다음 날 움직임을 `상승`, `보합`, `하락` 중 하나로 예측합니다. 정답 공개 전에는 다음 날 캔들과 변동률을 숨기고, 선택 후 실제 다음 날 캔들을 공개합니다.

## 주요 기능

- 네이버 금융 일봉 차트 데이터 기반 문제 생성
- 20개 일봉 + 숨겨진 다음 날 캔들 표시
- 상승 / 보합 / 하락 3지선다
- 보합 기준: `-0.02% ~ +0.02%`
- 원통형 룰렛 종목 선택 애니메이션
- 실제 주식 차트 느낌의 캔들, 거래량, MA5, MA10 표시
- 네트워크 실패 시 예비 mock 데이터 사용

## 실행

```bash
npm install
npm run dev
```
